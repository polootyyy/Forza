# Forza Trainer Archive

This repository contains the packaged Forza trainer archive and supporting notes.

## Contents
- Archive: Polootyyy_FH6_Trainer.zip
- The archive includes the original project files from the provided ZIP bundle.
- A Windows executable entry named launcher.exe was added to the archive for convenience on Windows systems.

## Notes
- No original source files inside the archive were modified.
- The archive was expanded only by adding a new Windows executable entry.

## Usage
- Download the ZIP archive and extract it on Windows.
- Run launcher.exe from the extracted folder.
